# 产研翻译小助手

当前阶段：按电子表格或 Wiki 链接和行号读取目标行，将简体中文翻译并回填空白语言列。

## 本地启动

1. 安装 Node.js 20 或更高版本。
2. 安装依赖：

   ```bash
   npm install
   ```

3. 复制环境变量模板：

   ```bash
   cp .env.example .env
   ```

4. 在 `.env` 中填写飞书开放平台“凭证与基础信息”页面里的 App ID 和 App Secret。
   测试 DeepSeek 时，同时填写：

   ```text
   AI_API_KEY=你的DeepSeek API Key
   AI_BASE_URL=https://api.deepseek.com
   AI_MODEL=deepseek-v4-flash
   ```
5. 启动：

   ```bash
   npm start
   ```

6. 在飞书中表达翻译需求，例如 `翻译`、`开始翻译`、`给我翻译一下` 或 `帮我做多语言`。

## 交互卡片（推荐）

机器人首先发送“使用说明 + 双模式入口”首页卡片，用户阅读必要条件后可直接选择：

1. **翻译新增内容**：表格新增内容后，用户填写电子表格链接和起始行；结束行选填，留空时只翻译一行。机器人动态识别目标语言列，翻译并补齐新增内容对应的全部语种。
2. **新增语种翻译**：用户填写电子表格链接、新语言表头名称和 BCP 47 标签。机器人预检全表，确认后追加新语言列，并翻译全部有效简体中文行。

模式首页本身就是内置的 **使用说明** 卡片。用户也可以直接发送“帮助”“使用说明”“说明书”“怎么用”或“如何使用”重新打开首页。

翻译新增内容模式的起始行和结束行都只允许填写数字，单次最多处理 100 行。

翻译时会自动读取同一行的 `功能版块`、`功能模块`、`说明`、`备注`、`key` 等非语言字段作为语义上下文，但不会把这些上下文字段写入译文。

提交按钮依赖飞书开发者后台的“卡片回传交互”回调，订阅方式请选择长连接。

### 开场卡片与机器人菜单

在飞书开发者后台的“事件与回调 → 事件配置”中，使用长连接订阅：

- 用户进入与机器人的会话：`im.chat.access_event.bot_p2p_chat_entered_v1`
- 机器人自定义菜单：`application.bot.menu_v6`

在“机器人 → 机器人自定义菜单”中开启悬浮菜单，并配置“推送事件”菜单项：

- `翻译新增内容`，事件 Key：`translate_existing`
- `新增语种翻译`，事件 Key：`translate_new_locale`
- 可选 `使用说明`，事件 Key：`translation_help`
- 可选 `翻译模式首页`，事件 Key：`translation_home`

用户进入机器人单聊时会自动收到模式选择卡片；点击菜单项会直接收到对应的任务表单。配置事件或菜单后需要创建并发布新的应用版本。

新增语种翻译模式会读取目标工作表的现有语言列：

- 若多数语言列使用 `Arabic(语言标签ar)`，新列沿用“名称 + 语言标签”格式。
- 若语言列使用 `简体中文`、`意大利语` 等纯名称，新列仅使用用户填写的名称。

机器人内部会把纯名称表头与语言标签的映射持久化到 `data/languages.json`，但不再向用户暴露独立的“添加语言配置”概念。

机器人会区分两类权限问题：读取阶段被拒绝时提示“机器人无法访问该表格”；可以读取但写入被拒绝时提示“机器人没有编辑权限”。对应按钮分别为“我已获得访问权限，重新检查”和“我已获得编辑权限，继续翻译”。点击后会恢复先前填写的链接与任务参数。机器人同时在服务端保存用户最近一次表单数据，避免飞书回调未完整返回按钮参数时出现空白表单。受飞书安全机制限制，未授权应用不能自行给自己提权。

机器人会缓存同一单聊的开场卡片发送时间，24 小时内用户离开并重新进入会话时不会重复推送使用说明，避免打断未完成任务。

## 文字命令（兼容）

发送：

```text
翻译 <飞书电子表格链接> 第15行
翻译 <飞书电子表格链接> 第15-30行
```

支持两种链接：

```text
https://xxx.feishu.cn/sheets/xxx
https://xxx.feishu.cn/wiki/xxx
```

对于 Wiki 链接，程序会先解析知识库节点，并确认底层对象确实是电子表格。

程序会扫描前 20 行并自动寻找语言表头，兼容两种格式：

- 标准格式：`简体中文(语言标签zh-Hans)`、`English(语言标签en)`
- 普通格式：`简体中文`、`English`、`French`、`German` 等

标准语言标签优先；普通格式按完整语言列名精确识别。

翻译采用“仅填空白”策略，不覆盖已有译文。写回前会再次检查简体中文是否变化。
若目标行存在已有译文，机器人会通过卡片按钮要求用户选择“覆盖”“仅填空白”或“取消”；
确认任务 10 分钟后自动失效。

若提示没有权限，请在目标电子表格右上角选择“…” → “更多” → “添加文档应用”，
添加“产研翻译小助手”并授予编辑权限。

不要提交或分享 `.env` 文件。
